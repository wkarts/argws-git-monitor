# Contribuição

1. Crie uma branch a partir de `main`.
2. Preserve a separação `backend`, `frontend`, `infra/scripts`.
3. Adicione testes para regras novas.
4. Execute `python scripts/validate-package.py`.
5. Abra PR com descrição funcional, riscos, migrations e evidências.

Commits seguem preferencialmente Conventional Commits (`feat`, `fix`, `docs`, `test`, `build`, `ci`, `chore`).
